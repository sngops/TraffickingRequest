Please Note:

  1. “Sets” refer to distinct versions tied to a job code. If you’re running banners under the same job code but with two different creative versions, each version will be treated as a separate set. (For example: JOBCODE123 static and JOBCODE123 animated = 2 sets; JOBCODE098 version A and JOBCODE098 version B = two sets)
  2. Only one static backup set is permitted per campaign. However, you can use as many static banner sets in the live rotation.
  3. The outlined scope assumes that all assets have already undergone QA and have received Sci-Reg approval. Trafficking review will be limited to a compatibility check via Campaign Manager 360 (CM360) for Ad Ops and final confirmation from Sci-Reg. If any functional issues are identified during the creative verification review, the scope of work will increase.
  4. For 1x1 placements, please confirm with the vendor what deliverables are required from Ad Ops. If the placement compatibility type is selected incorrectly in Prisma, additional scope and effort may be needed to resolve the issue.
